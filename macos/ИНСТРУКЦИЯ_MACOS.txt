========================================================================
             E-COMMERCE ANALYTICS DASHBOARD ДЛЯ macOS
========================================================================

Данная папка содержит все компоненты для сборки и запуска дашборда на macOS.

------------------------------------------------------------------------
1. КАК ЗАПУСТИТЬ ПРИЛОЖЕНИЕ (3 СПОСОБА)
------------------------------------------------------------------------

СПОСОБ 1: Нативное приложение macOS (Рекомендуется)
  • Просто дважды кликните на "E-Commerce Dashboard.app"
  • Откроется полноценное нативное окно приложения с дашбордом.
  • Сервер автоматически стартует в фоне, а при закрытии окна (или Cmd+Q) 
    сервер корректно завершит работу.
  • Горячие клавиши в приложении:
      - Cmd + R : Перезагрузить страницу
      - Cmd + B : Открыть текущую страницу в системном браузере (Safari/Chrome)
      - Правый клик -> "Inspect Element" : Инструменты разработчика для отладки

СПОСОБ 2: Через скрипт быстрого запуска
  • Дважды кликните на файл "Запустить Дашборд.command" (или запустите ./launch.sh)
  • В терминале отобразится лог старта, а страница откроется в вашем браузере.

СПОСОБ 3: В режиме активной веб-разработки (с автообновлением / Hot Reload)
  • Откройте Терминал в папке проекта:
      cd frontend
      npm run dev
  • Откройте в браузере: http://localhost:3000

------------------------------------------------------------------------
2. КАК ОСТАНОВИТЬ СЕРВЕР
------------------------------------------------------------------------
  • Если вы использовали .app: просто закройте окно или нажмите Cmd+Q.
  • В веб-интерфейсе: нажмите красную кнопку "Завершить работу" в шапке.
  • Через скрипт: дважды кликните на "Остановить.command" (или ./stop.sh).

------------------------------------------------------------------------
3. ПАПКА ДАННЫХ И ОТЧЕТОВ
------------------------------------------------------------------------
  • Все данные (база SQLite dashboard.db, отчеты по рекламе и продажам,
    а также server.log) хранятся в подпапке data/.
  • Папки для отчетов Excel:
      - data/ads/    : отчеты по рекламе
      - data/sales/  : отчеты по продажам
  • Вы также можете выбрать любые другие удобные папки через всплывающее 
    окно "Синхронизация данных" в интерфейсе дашборда — на macOS откроется 
    нативный диалог выбора папки Finder!

------------------------------------------------------------------------
4. КАК ПЕРЕСОБРАТЬ ПРИЛОЖЕНИЕ (.app)
------------------------------------------------------------------------
  Если вы внесли изменения в код фронтенда или ETL-скрипты:
  1. Запустите в терминале:
       ./macos/build_macos.sh
  2. Скрипт автоматически:
       - Скомпилирует ETL бинарник через PyInstaller
       - Соберет продакшн Next.js Standalone
       - Скомпилирует нативный лаунчер
       - Соберет свежий бандл "E-Commerce Dashboard.app"
       - Упакует дистрибутив в dist_macos/ и ZIP в release_macos/
