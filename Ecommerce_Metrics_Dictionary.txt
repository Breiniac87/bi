СЛОВАРЬ МЕТРИК ПРОЕКТА: E-COMMERCE АНАЛИТИКА РЕКЛАМЫ И ПРОДАЖ
================================================================================

ВАЖНОЕ ВВЕДЕНИЕ: ЛОГИКА АЛЛОКАЦИИ (ВЕС РК)
Чтобы избежать задвоения общих продаж при склейке с несколькими рекламными кампаниями (РК) за один день, в проекте используется "Вес РК". 
Вес РК = Расходы на конкретную РК / Общие расходы на товар за день.
Все общие метрики (Заказы всего, Выкупы, Отмены) умножаются на этот вес. Это позволяет честно распределить органические продажи между всеми активными кампаниями пропорционально их бюджету.

--------------------------------------------------------------------------------
1. БАЗОВЫЕ РЕКЛАМНЫЕ МЕТРИКИ (ТРАФИК)
--------------------------------------------------------------------------------
1. Расходы на РК (₽)
   - Для чего нужна: Оценка затраченного бюджета на конкретную кампанию.
   - Расчет: Прямая сумма из отчета WB/Ozon (Затраты на рекламу).

2. Показы
   - Для чего нужна: Оценка охвата аудитории. Сколько раз карточка попалась на глаза покупателям.
   - Расчет: Прямая сумма из рекламного отчета.

3. Клики
   - Для чего нужна: Оценка объема привлеченного трафика на карточку.
   - Расчет: Прямая сумма из рекламного отчета.

4. Ставка за 1000 (CPM, ₽)
   - Для чего нужна: Показывает стоимость покупки 1000 показов. Метрика конкуренции в аукционе.
   - Расчет: (Расходы на РК / Показы) * 1000

5. Цена за клик (CPC, ₽)
   - Для чего нужна: Отражает стоимость одного перехода в карточку. Помогает понять, насколько дорого обходится трафик.
   - Расчет: Расходы на РК / Клики

6. % CTR (Кликабельность)
   - Для чего нужна: Оценка привлекательности главной фотографии, цены и отзыва в выдаче.
   - Расчет: (Клики / Показы) * 100

7. Медианная позиция
   - Для чего нужна: Показывает, на каком реальном месте в среднем показывался товар.
   - Расчет: Среднее значение из рекламного отчета.

--------------------------------------------------------------------------------
2. ВОРОНКА КОНВЕРСИЙ (CR)
--------------------------------------------------------------------------------
8. Корзины (всего)
   - Для чего нужна: Показывает объем добавления товара в корзину с рекламы.
   - Расчет: Корзины (прямая) + Корзины (ассоциированная атрибуция).

9. % CR клик - корзина
   - Для чего нужна: Конверсия из захода в карточку в добавление в корзину. Отражает качество контента внутри карточки (инфографика, описание, отзывы).
   - Расчет: (Корзины / Клики) * 100

10. % CR корзина - заказ
    - Для чего нужна: Показывает, какой процент положивших в корзину дошел до оплаты/оформления.
    - Расчет: (Заказы по РК / Корзины) * 100

11. % CR клик - заказ
    - Для чего нужна: Главная метрика конверсии карточки (из клика сразу в покупку).
    - Расчет: (Заказы по РК / Клики) * 100

--------------------------------------------------------------------------------
3. ЭКОНОМИКА РЕКЛАМЫ (ПРЯМАЯ)
--------------------------------------------------------------------------------
12. Заказов шт. (по РК)
    - Для чего нужна: Количество заказов, совершенных непосредственно благодаря клику по рекламе.
    - Расчет: Прямые заказы + Ассоциированные заказы.

13. Сумма заказов (по РК)
    - Для чего нужна: Выручка в заказах, которую принесла сама реклама.
    - Расчет: GMV прямая + GMV ассоциированная.

14. Стоимость заказа (по РК, ₽/шт)
    - Для чего нужна: Сколько рекламных денег потрачено на привлечение 1 рекламного заказа (CPA).
    - Расчет: Расходы на РК / Заказов шт. (по РК)

15. % ДРР / по РК
    - Для чего нужна: Доля рекламных расходов от сумм рекламных заказов. Эффективность кампании "в вакууме" без учета органики.
    - Расчет: (Расходы на РК / Сумма заказов по РК) * 100

--------------------------------------------------------------------------------
4. ОБЩАЯ ЭКОНОМИКА (АЛЛОЦИРОВАННАЯ, С УЧЕТОМ ОРГАНИКИ)
--------------------------------------------------------------------------------
16. Заказов шт. (всего)
    - Для чего нужна: Истинный масштаб продаж товара за день (реклама + органика), отнесенный к данной кампании.
    - Расчет: Сырые общие заказы * Вес РК

17. Сумма заказов (всего, ₽)
    - Для чего нужна: Общая сумма заказов (реклама + органика), привязанная к кампании.
    - Расчет: Сырая сумма заказов * Вес РК

18. Сумма выкупов (₽)
    - Для чего нужна: Фактические деньги, которые покупатели оплатили на ПВЗ (без учета возвратов).
    - Расчет: Сырая сумма выкупов * Вес РК

19. Стоимость заказа (всего, ₽/шт)
    - Для чего нужна: Истинная цена привлечения 1 заказа (CPO) с учетом того, что реклама бустит органику.
    - Расчет: Расходы на РК / Заказов шт. (всего)

20. % ДРР / общий
    - Для чего нужна: Доля рекламных расходов от ОБЩЕЙ суммы заказов. Главная метрика планирования юнит-экономики.
    - Расчет: (Расходы на РК / Сумма заказов всего) * 100

21. ДРР продажи (%)
    - Для чего нужна: Самая строгая метрика ДРР. Считается не от виртуальных "заказов", а от реальных "выкупов" (денег в кассе).
    - Расчет: (Расходы на РК / Сумма выкупов) * 100

--------------------------------------------------------------------------------
5. СТРАТЕГИЧЕСКИЕ МЕТРИКИ И КАЧЕСТВО
--------------------------------------------------------------------------------
22. Доля органики (%)
    - Для чего нужна: Показывает процент "бесплатных" заказов, которые пришли без прямого клика по рекламе.
    - Расчет: ((Заказов всего - Заказов по РК) / Заказов всего) * 100

23. Halo-эффект (Мультипликатор)
    - Для чего нужна: Показывает силу рекламного буста. Значение "1.5" означает, что 1 рекламный заказ приносит еще 0.5 органического сверху.
    - Расчет: Заказов шт. (всего) / Заказов шт. (по РК)

24. Средний чек (AOV, ₽)
    - Для чего нужна: Средняя стоимость одной единицы заказанного товара.
    - Расчет: Сумма заказов (всего) / Заказов шт. (всего)

25. Доля отмен и возвратов (%)
    - Для чего нужна: Фильтр качества трафика и товара. Высокий % говорит о браке, несоответствии фото или плохом качестве лидов.
    - Расчет: ((Отмены шт + Возвраты шт) / Заказов шт. всего) * 100

26. Истинный ROAS (выручка на 1₽)
    - Для чего нужна: Показывает, сколько реальных рублей (в выкупах) приносит 1 вложенный в рекламу рубль.
    - Расчет: Сумма выкупов / Расходы на РК

--------------------------------------------------------------------------------
6. ЦЕНООБРАЗОВАНИЕ И СПП
--------------------------------------------------------------------------------
27. Цена до СПП (Скидки Постоянного Покупателя)
    - Для чего нужна: Цена, которую установил селлер.
    - Расчет: Усредненное значение из отчета о продажах.

28. Цена после СПП
    - Для чего нужна: Реальная цена, которую видел и заплатил клиент (с учетом скидки от маркетплейса).
    - Расчет: Усредненное значение из отчета о продажах.

29. СПП %
    - Для чего нужна: Размер субсидии от маркетплейса. Важно мониторить для понимания конкурентоспособности цены.
    - Расчет: Усредненное значение из отчета о продажах.
