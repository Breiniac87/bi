# E-Commerce Analytics Dashboard

Аналитический дашборд для отслеживания эффективности продаж и рекламы на маркетплейсах. Приложение автоматически выгружает сырые отчеты с Яндекс.Диска, сводит их в единую базу данных (SQLite) и отображает ключевые показатели в интерактивном веб-интерфейсе.

Проект состоит из двух частей:
1. **Python-скрипт (Data Pipeline)** — парсит Excel-отчеты с Яндекс.Диска и подготавливает данные.
2. **Next.js (Frontend)** — современный веб-интерфейс для визуализации данных.

---

## 📊 Какие метрики мы считаем

Дашборд сводит данные по чистой органике и рекламным кампаниям. Все метрики считаются без потерь и дубликатов с использованием `Full Outer Join`.

**Базовые показатели:**
- **Заказов шт. (всего / по РК)** — общее количество заказов и заказы, атрибутированные к рекламе.
- **Сумма заказов / GMV (всего / по РК)** — общая сумма заказов.
- **Сумма выкупов** — сумма выкупленных товаров (за вычетом возвратов и отмен).
- **Расходы на РК** — затраты на рекламные кампании.
- **Воронка продаж** — Показы $\rightarrow$ Клики $\rightarrow$ Добавления в корзину.
- **Отмены и возвраты** — в штуках.

**Производные (вычисляемые) метрики:**
- **% CTR (Click-Through Rate)** — кликабельность рекламы (Клики / Показы).
- **Цена за клик (CPC)** — стоимость одного перехода (Расходы / Клики).
- **Цена корзины (CPA)** — стоимость добавления в корзину (Расходы / Корзины).
- **Средний чек (AOV)** — средняя сумма заказа.
- **% CR (Conversion Rate)** — конверсия из клика в корзину и в заказ.
- **% ДРР (Доля рекламных расходов)** — отношение расходов к выручке. Считается в двух вариантах:
  - *Локальный ДРР* (Расходы / Сумма заказов по рекламе).
  - *Общий ДРР* (Расходы / Общая сумма заказов компании).
- **ROMI (Окупаемость)** — рентабельность инвестиций в маркетинг.
- **Доля рекламных продаж** — % заказов, пришедших с рекламы, от общего объема.
- **Доля отмен и возвратов** — % отказов от общего числа заказов.

## 🚀 Как запустить проект с нуля (на локальном ПК или сервере)

Для работы вам потребуется установленные **Python 3.10+** и **Node.js 18+**.

### Шаг 1. Настройка окружения
В корневой папке проекта должен лежать файл `.env` с вашим токеном от Яндекс.Диска:
```env
YANDEX_DISK_TOKEN="y0_AgAAAA..."
```

### Шаг 2. Подготовка базы данных (Python)
В первую очередь необходимо скачать исходные Excel-файлы и сгенерировать базу данных SQLite.

1. Откройте терминал в корневой папке проекта.
2. Создайте виртуальное окружение:
   ```bash
   python3 -m venv venv
   ```
3. Активируйте виртуальное окружение:
   - macOS/Linux: `source venv/bin/activate`
   - Windows: `venv\Scripts\activate`
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
5. Запустите скрипт синхронизации:
   ```bash
   python3 sync_yandex_to_sqlite.py
   ```
   *Скрипт подключится к Яндекс.Диску, скачает новые файлы и создаст файл `dashboard.db`.*

> **Важно:** Запускайте этот скрипт периодически (например, через Cron), чтобы дашборд получал свежие данные!

### Шаг 3. Запуск веб-интерфейса (Next.js)
После того как файл `dashboard.db` создан, можно запускать графический интерфейс.

1. Перейдите в папку фронтенда:
   ```bash
   cd frontend
   ```
2. Установите NPM-зависимости (нужно сделать только один раз):
   ```bash
   npm install
   ```
3. Запустите сервер:
   - Для разработки (с автообновлением): `npm run dev`
   - Для production (на сервере): `npm run build` затем `npm run start`

**Готово!** Интерфейс дашборда будет доступен в браузере по адресу: [http://localhost:3000](http://localhost:3000)

## 🪟 Сборка портативной версии (Portable) для Windows 10 / 11

Проект собирается в виде автономной **портативной папки без установки** (`E-Commerce-Dashboard-Portable`), внутри которой находится исполняемый файл `E-Commerce Dashboard.exe`.
- Работает без установки Node.js или Python на целевой машине.
- Не требует прав администратора.
- Все данные (база SQLite, настройки и отчеты) сохраняются локально в подпапке `data/`, поэтому папку можно свободно переносить на флешку или другой компьютер.

### Вариант 1. Автоматическая облачная сборка через GitHub Actions (Рекомендуется)
Если вы работаете на macOS и хотите сразу получить готовый ZIP-архив:
1. Отправьте изменения в репозиторий GitHub (`git push`).
2. В GitHub перейдите во вкладку **Actions** $\rightarrow$ выберите workflow **"Build Windows Portable Release"** $\rightarrow$ нажмите **"Run workflow"**.
3. Облачный раннер Windows соберет проект, создаст портативную папку и упакует её в ZIP-архив.
4. Готовый архив **`E-Commerce-Dashboard-Portable-v1.0.2.zip`** появится во вкладке **Artifacts** (или в Releases при создании тега `v*`).
5. Распакуйте архив и запустите `E-Commerce Dashboard.exe` — интерфейс сразу откроется в окне программы!

### Вариант 2. Локальная сборка на компьютере с Windows
1. Склонируйте репозиторий на Windows 10/11.
2. Убедитесь, что установлены **Python 3.10+** и **Node.js 18+**.
3. Запустите скрипт сборки:
   ```cmd
   windows\build_portable.bat
   ```
4. Готовая портативная папка появится в `dist_windows\E-Commerce-Dashboard-Portable\`, а готовый к отправке архив — в `release_windows\E-Commerce-Dashboard-Portable-v1.0.2.zip`.
