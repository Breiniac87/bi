================================================================================
КАК ПОЛУЧИТЬ И ЗАПУСТИТЬ ГОТОВЫЙ E-Commerce-Dashboard-Setup.exe ДЛЯ WINDOWS
================================================================================

В проекте настроено два способа получения готового установщика Setup.exe:

--------------------------------------------------------------------------------
СПОСОБ 1 (САМЫЙ ПРОСТОЙ, ЕСЛИ ВЫ НА MAC): ОБЛАЧНАЯ СБОРКА ЧЕРЕЗ GITHUB ACTIONS
--------------------------------------------------------------------------------
Вам вообще не нужен компьютер с Windows! Microsoft GitHub сам соберет .exe в облаке:

1. Загрузите проект в ваш GitHub-репозиторий:
   git add .
   git commit -m "Update"
   git push origin main

2. Откройте ваш репозиторий на сайте GitHub в браузере.
3. Перейдите во вкладку "Actions" в верхнем меню.
4. В списке слева нажмите "Build Windows Release".
5. Справа нажмите кнопку "Run workflow" -> выберите ветку main -> "Run workflow".
6. Подождите 3-5 минут, пока идет сборка на виртуальном сервере Windows.
7. После завершения сборки откройте этот запуск и в блоке "Artifacts" скачайте архив
   "E-Commerce-Dashboard-Windows-Setup.zip".
8. Внутри архива лежит готовый файл "E-Commerce-Dashboard-Setup.exe".
   Его можно отправить любому пользователю Windows 10/11!

--------------------------------------------------------------------------------
СПОСОБ 2: ЛОКАЛЬНАЯ СБОРКА НА КОМПЬЮТЕРЕ С WINDOWS 10/11
--------------------------------------------------------------------------------
Если у вас есть компьютер с Windows (или вы передали проект коллеге на Windows):

1. Убедитесь, что на компьютере с Windows установлены:
   - Python 3.10+ (с галочкой "Add python.exe to PATH" при установке)
   - Node.js 18+ или 20+ (https://nodejs.org/)
   - Inno Setup 6 (https://jrsoftware.org/isdl.php)

2. Откройте папку "windows" и дважды кликните по файлу:
   build_installer.bat

3. Скрипт сам скомпилирует Python ETL, соберет веб-сервер и вызовет Inno Setup.
4. Готовый установщик появится в папке:
   release_windows\E-Commerce-Dashboard-Setup.exe

--------------------------------------------------------------------------------
КАК ПРОСТО ЗАПУСТИТЬ ПРИЛОЖЕНИЕ В ПАПКЕ (БЕЗ УСТАНОВКИ):
--------------------------------------------------------------------------------
Если проект уже лежит на Windows и вы хотите сразу открыть дашборд:
- Дважды кликните по файлу: windows\launch.bat (или windows\launcher.vbs).
- Приложение запустится и откроется в отдельном окне Microsoft Edge.
- При закрытии окна сервер автоматически выключится.
- Для принудительной остановки сервера запустите: windows\stop.bat
