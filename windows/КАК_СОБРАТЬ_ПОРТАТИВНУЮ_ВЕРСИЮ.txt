     СБОРКА ПОРТАТИВНОЙ ВЕРСИИ (PORTABLE) ДЛЯ WINDOWS 10 / 11
================================================================================

Формат портативной версии:
Готовая папка "E-Commerce-Dashboard-Portable", внутри которой находится:
  • "E-Commerce Dashboard.exe" — исполняемый файл для запуска без установки
  • "Запустить Дашборд.bat" — альтернативный скрипт запуска
  • "Остановить.bat" — скрипт корректной остановки
  • "ИНСТРУКЦИЯ.txt" — памятка для пользователя
  • Встроенный Node.js, движок ETL на Python и Next.js Standalone сервер
  • Папка "data\" — изолированное хранилище базы данных и отчетов

Эту папку (или сгенерированный zip-архив) можно распаковать на любом компьютере
с Windows 10/11 и запустить без установки каких-либо сторонних программ
(Node.js и Python устанавливать не нужно, права администратора не требуются).


СПОСОБ 1. Сборка через GitHub Actions (в 1 клик, не нагружая ваш компьютер):
-------------------------------------------------------------------------
1. Откройте ваш репозиторий на GitHub в браузере.
2. Перейдите во вкладку "Actions".
3. В левой колонке выберите workflow "Build Windows Portable Release".
4. Нажмите кнопку "Run workflow" -> выберите ветку "main" -> нажмите "Run workflow".
5. Через 3–5 минут перейдите в завершившийся запуск и в разделе "Artifacts"
   скачайте готовый архив:
   "E-Commerce-Dashboard-Portable-v1.0.5.zip".
6. Распакуйте архив в любое место и кликните "E-Commerce Dashboard.exe"!


СПОСОБ 2. Локальная сборка на компьютере с Windows:
---------------------------------------------------
Требования:
- Windows 10 или 11 (x64)
- Установленный Python 3.10+ (добавлен в PATH)
- Установленный Node.js 18+ (добавлен в PATH)
- Visual Studio Build Tools (C++ compiler) ИЛИ GCC (MinGW) для сборки exe-лаунчера

Инструкция:
1. Откройте папку проекта.
2. Запустите скрипт:
   windows\build_portable.bat
3. Скрипт в автоматическом режиме:
   - Скомпилирует Python ETL в автономный бинарник (PyInstaller);
   - Соберет Next.js standalone сервер;
   - Скомпилирует нативный GUI-лаунчер "E-Commerce Dashboard.exe" с иконкой;
   - Упакует рантайм node.exe и сформирует готовую папку dist_windows\E-Commerce-Dashboard-Portable;
   - Создаст готовый архив release_windows\E-Commerce-Dashboard-Portable-v1.0.5.zip.
4. Готово! Папка и zip-архив готовы к использованию и распространению.
